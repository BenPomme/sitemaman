# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Professional portfolio website for Sylviane Bahr, a Gestalt therapist and coach in Sant Cugat, Spain. Static site with trilingual support (French, English, Spanish).

## Development

**No build process required** - Pure HTML/CSS/JS static site.

To run locally, serve from any static web server on port 8080. VS Code Chrome debugger is pre-configured in `.vscode/launch.json`.

## Architecture

### Internationalization System
- All user-facing text lives in `translations.js` (FR/EN/ES)
- HTML elements use `data-i18n="key"` for text content
- Form inputs use `data-i18n-placeholder="key"` for placeholders
- Language persists in localStorage as `site-lang`
- `app.js` handles language switching via dropdown

### Styling Architecture
- Read `DESIGN.md` first: it is the design brief, token table and QA gate for this site.
- `base.css` is the original base layer; `theme.css` loads after it and defines the current look (tokens on `:root`, header, home page, inner pages). Change tokens in `theme.css`, not `base.css`.
- `landing.css` styles the online-offer landing pages (`body.page-online-therapy--offer`); `local-offer.css` styles the Sant Cugat local pages.
- Warm paper and brown palette: `--paper #f6f3ee`, `--cream #efe9df`, `--brown #2b1a12`, `--ink #17191b`, `--muted #6f665e`.
- Responsive breakpoints: 1359px (nav collapses to the Menu button; keep in sync with `app.js`), 980px (layout shift), 720px (mobile adjustments).
- Stylesheet, `translations.js` and `app.js` links carry a `?v=YYYYMMDD` cache version; bump it on every page when the file changes.

### Page Structure
All pages share the same ticker, header, nav and footer markup. Main pages: `index.html`, `therapy.html`, `coaching.html`, `groups.html`, `cercle-hommes-sant-cugat.html`, `compare.html`, `about.html`, `cv.html`, `resources.html`, `reflections.html`, `appointments.html` (booking), `contact.html`, `legal.html`, `privacy.html`. The remaining root pages are search and ad landing pages in FR, EN and ES.

`guides/*.html` and the guides block in `resources.html` are generated by `scripts/generate_guides.py` from `seo/` (see `seo/README.md`); do not hand-edit them. `_config.yml` keeps `seo/`, `scripts/`, `docs/` and the Markdown docs out of the published site.

## Key Conventions

**Adding new text:** Always add translations to all three languages in `translations.js`, then reference via `data-i18n` attribute.

**CSS naming:** BEM-like with double underscores (`.card__header`). Use existing CSS variables for colors.

**JavaScript:** camelCase. Forms use `appointment-form` and `contact-form` IDs for handling in `app.js`.

**Fonts:** Schibsted Grotesk (headings and body) and DM Mono (short uppercase labels only) via Google Fonts.
